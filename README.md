# Solar Installation Management System (SIMS)

Enterprise-grade operations, pipeline tracking, inventory logistics, and customer lifecycle management platform tailored for rooftop solar installers and EPC contractors.

## Project Structure

```
Solar-managemenet-system/
├── frontend/             # React 18 + Vite + Redux Toolkit + Tailwind CSS SPA
│   ├── src/              # Application source code
│   ├── public/           # Static assets and icons
│   ├── .env.example      # Environment variables template
│   ├── package.json      # Dependencies and scripts
│   └── vite.config.js    # Vite bundler configuration
└── (backend/)            # Future FastAPI / PostgreSQL backend services
```
